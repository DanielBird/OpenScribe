# Phase 5 — DOCX export

**Goal:** A **Download .docx** button produces a clean Word document: a header block, then one paragraph per
turn (`[HH:MM:SS] Speaker: text`), using the current speaker names. If an English translation exists, the user
chooses Original or English.

**Depends on:** Phase 1 for the core (`docxModel`, `fileName`). Phase 4 for the UI (button, dialog).

**Read first:** [DECISIONS.md](../DECISIONS.md) D8, D9, [ROADMAP.md](../ROADMAP.md) §6.

## Tasks

1. **Dependency:** add `docx` as a runtime dependency (and `jszip` as a dev dependency for tests; `docx` already
   uses it internally).
2. **`src/features/export/docxModel.ts`** (pure, no `docx` import): `buildDocModel(doc, { version, generatedAt })
   → DocModel`.
   - Title: `Transcript – <file name without extension>`.
   - Meta rows, in this order:
     - *Source file*: the name.
     - *Duration*: `HH:MM:SS`, from `result.audioDurationSec`, falling back to `source.durationSec`.
     - *Transcribed*: `doc.createdAt`, formatted `d MMMM yyyy, HH:mm` (`en-GB`).
     - *Language*:
       - Original: `German (detected)`.
       - English: `English (translated from German with Claude, claude-opus-5-5)`.
     - *Speakers*: the labels joined with `, `.
     - *Transcription*: `ElevenLabs scribe_v2`, plus ` · glossary of N terms` if N > 0.
     - *Exported*: `generatedAt`.
   - Paragraphs: for each turn, `{ timestamp: formatTimestamp(start), speaker: label, text }`. For `version
     'en'`, the text is `doc.translations.en.texts[turn.id]`. A missing translation for any turn throws
     `Error('translation incomplete')`.
3. **`src/features/export/fileName.ts`:** `exportFileName(doc, version)` returns `<base> - transcript
   (<German|English|…>).docx`.
   - `<base>` is the source name without its extension, with Windows-reserved characters `<>:"/\|?*` and
     control characters replaced by `_`, trimmed, and truncated to 120 characters.
4. **`src/features/export/docxRender.ts`:** `renderDocx(model): Promise<Blob>` using `docx` (`Document`,
   `Paragraph`, `TextRun`, `HeadingLevel`, `Packer.toBlob`).
   - Default font Calibri 11 pt. The title uses Heading 1.
   - Meta rows are plain paragraphs: the label in bold, then the value. They are followed by an empty paragraph
     and a thin bottom border or a "Transcript" Heading 2.
   - Each turn paragraph has three runs: the timestamp in grey (`666666`), the speaker label in bold followed by
     `: `, and the text. Spacing after is 120 twips. Word's own line wrapping applies.
   - Document properties: `title`, `creator: 'Describe'`, `description: 'Generated by Describe v<version>'`.
5. **`src/features/export/download.ts`:** `downloadBlob(blob, fileName)` creates a temporary `<a download>` with an
   object URL, clicks it, and revokes the URL on the next tick. It works from `file://` in Chromium.
6. **`ExportDialog.vue`** + button on `OutputView`
   - The **Download .docx** button is enabled when `doc` exists and there are more than 0 turns.
   - With no translation, clicking downloads the original directly. With a translation, the dialog opens with the
     choice *Original (German)* / *English translation*. The default is the version currently shown in the view.
   - Errors (unlikely) show inline. The button shows a spinner while rendering (big documents can take about 1 s).

## Contracts introduced

```ts
// src/features/export/docxModel.ts
export interface DocModel {
  title: string;
  meta: { label: string; value: string }[];
  paragraphs: { timestamp: string; speaker: string; text: string }[];
  properties: { title: string; description: string };
}
export function buildDocModel(doc: TranscriptDoc, opts: { version: TranscriptVersion; generatedAt: Date; appVersion: string }): DocModel;

// src/features/export/docxRender.ts
export function renderDocx(model: DocModel): Promise<Blob>;

// src/features/export/fileName.ts
export function exportFileName(doc: TranscriptDoc, version: TranscriptVersion): string;

// src/features/export/download.ts
export function downloadBlob(blob: Blob, fileName: string): void;
```

### 2026-10-13 — Phase 5 done (branch `phase-5-docx-export`, based on `main` at `40553a1`)

**Word check: passed.** The maintainer opened the three e2e exports in Word on Windows: English with a renamed
speaker, English translation, and German original. There were no repair prompts and the layout looked right. No
screenshot was added. To repeat the check, run `npm run test:e2e`; it leaves the files in
`test-results/export.e2e.ts-*/`.

**Dependency findings**
- `docx` 9.10.0 ships a pre-bundled ESM build with its own Node polyfills (no bare imports), so Vite needs no
  polyfill plugin. Its typings import `stream` types, but the app's `types: []` + `skipLibCheck` keep Node globals
  out, and typecheck passes. No DECISIONS.md entry was needed.
- The only `new Function` in the bundle is JSZip's `setImmediate(string)` fallback, which never runs. The e2e
  console guard sees no CSP violation during a real export.
- **Bundle:** 632 KB (198 KB gzip), up from 226 KB (76 KB gzip), so docx + JSZip add about 406 KB. This is well
  under the 3 MB warning.

**Decisions (taken in the plan, approved by the maintainer)**
- Dates use `formatDateTime` ("13 Oct 2026, 14:05"), the same as the Output header. The draft asked for
  "13 October 2026, 14:05".
- A thin bottom border under the last meta row separates the details from the turns. There is no "Transcript"
  Heading 2, because the title already says "Transcript".
- *Language* says "German (detected)" only when the language was auto-detected; a chosen language reads "German".
- The *Duration* row is left out when no duration is known (as in the UI header).
- **New store `stores/export.ts`** (`busy`, `error`, `hasTranslation`, `download(version)`), because components talk
  to stores (AGENTS rule 4). It clears its error when another transcript is shown.
- Every string goes through `xmlSafe()` in `docxRender.ts`, which strips control characters, U+FFFE/U+FFFF and
  unpaired surrogates. One such character from a file name or an LLM reply would otherwise make Word report the
  file as damaged. **Phase 6** doesn't need to sanitise translations for export.

**Contract changes and additions**
- `buildDocModel(doc, { version, generatedAt, appVersion, timeZone? })`: `timeZone` is for tests only.
- `fileName.ts` also exports `fileBaseName()` (used for the title) and `MAX_BASE_LENGTH`. A sanitised base that
  ends up empty becomes `Untitled`.
- `docxRender.ts` also exports `xmlSafe()`.
- `ConfirmDialog` has a default slot below the message, and `message` is optional. Without a message there is no
  `<p>` and no `aria-describedby`. `ExportDialog` is built on it, so focus, Escape and focus return are shared.
- `.spinner` (and `@keyframes spin`) moved from `JobStatus.vue` to `base.css`; a component sets the size.
- Test helpers: `withTranslation(doc, texts?)` and `TEST_TRANSLATION_TEXTS` in `src/testing/transcriptDoc.ts`. The
  ElevenLabs route mock and the Setup/Run steps (`mockElevenLabs`, `ok(delay, fixture)`, `fixture`, `goToGlossary`,
  `run`, `TONE_WAV`) moved from `transcribe.e2e.ts` into `tests/e2e/helpers.ts`.

**UI text trimmed (D13)**
- The dialog title is "Which version?", with the radios *Original (German)* / *English translation* (visually
  hidden legend "Version") and the buttons **Cancel** / **Download**. Focus starts on **Download**.
- **Download .docx** is hidden, not disabled, when a doc has 0 turns. "No speech was detected" already explains why.
